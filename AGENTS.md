# PayWay integration instructions for AI agents

When the developer works on ABA PayWay payments, read `skills/using-payway/SKILL.md` in this
repository (or https://github.com/seabnavin19/payway-skill/blob/master/skills/using-payway/SKILL.md)
and follow it. It routes you to the other skills in `skills/`.

All PayWay facts come from the knowledge base index: https://seabnavin19.github.io/payway-skill/llms.txt
Never invent PayWay field names, endpoints or hash rules. Never ask for secrets in chat.
